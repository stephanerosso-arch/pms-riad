# pms-riad

Scripts Google Apps Script pour l'extraction et le traitement des e‑mails de réservation et l'alimentation de Google Sheets (PMS simple pour un riad).

Note sur les données d'exemple

- Le dépôt contient un export Excel `recupMail.xlsx` (actuellement placé à la racine). Il s'agit d'un export d'exemple destiné aux tests. Idéalement ce fichier devrait être déplacé dans le dossier `data/`.
- J'ai ajouté `data/README.md` avec les instructions pour gérer les exports d'exemple.

Prochaines actions possibles

- Déplacer `recupMail.xlsx` dans `data/` (je peux le faire si tu confirmes). 
- Me fournir un extrait CSV de l'onglet `dataMail` (en-tête + ~10 lignes) pour que je vérifie les indices de colonnes et prépare la correction de `recupDataMailOptim`.
